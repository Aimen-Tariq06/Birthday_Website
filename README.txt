LISHY BIRTHDAY WEBSITE
======================
Kaise kholein:
1. Zip ko Extract karo.
2. VS Code mein File > Open Folder karke ye folder kholo.
3. index.html par right click > "Open with Live Server" (ya index.html par double click karo).

Files:
- index.html  : website ka structure (pages)
- style.css   : colours, fonts aur design
- script.js   : saari logic. Sabse upar CONFIG (var C={...}) mein passcode, naam, date, letter badlo.
- images/     : saari photos (cake1.jpg last page ki photo hai). Nayi photo lagani ho to isi naam se replace kar do.

Gaana lagane ke liye: song.mp3 isi folder mein rakho aur script.js mein song:"" ko song:"song.mp3" kar do.
